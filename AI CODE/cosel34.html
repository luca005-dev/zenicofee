Add this to the CSS: ```css /* Visually hides content while keeping it available to screen readers. */ .sr-only { position: absolute; width: 1px; height: 1px; padding: 0; margin: -1px; overflow: hidden; clip: rect(0, 0, 0, 0); white-space: nowrap; border: 0; } ``` ### What changed for screen readers? The key improvement is this combination: ```html aria-current="true" aria-hidden="false" tabindex="0" ``` for the **active slide**, while inactive slides use: ```html aria-current="false" aria-hidden="true" tabindex="-1" ``` So a screen reader can understand: > **"Featured products, carousel. Slide 2 of 5: Item 2."** rather than encountering all five slides as though they were simultaneously active. The separate live region: ```html
